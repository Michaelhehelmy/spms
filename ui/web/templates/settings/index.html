  • Inventory CSV (easiest for barcodes/bulk items): download the inventory template or export current inventory CSV, fill all item fields (name/category/unit/cost/price/stock, SKU, barcode, barcode_type, track_batches, shelf_life_days, thresholds, supplier, active), then upload as CSV.   • CSV inventory import behavior: replaces inventory from the CSV and keeps current rooms/rate plans/expense categories/activities; meals/recipe links are cleared for safety because item IDs/names may change (re-add meals after import if needed).   • Reset: resets settings to defaults (confirmation RESET DEFAULTS, preserves schema/language).

LAN / Network access (PWA & other devices)

To access SPMS from phones/tablets/other PCs on the same network, run the server on host 0.0.0.0 (launcher menu: LAN mode or --host 0.0.0.0) with a fixed port and SQLite-safe --workers 1.

  • Stable same IP: set a static/DHCP-reserved LAN IP for this machine so the URL stays the same across restarts (required for a PWA to auto-reconnect to the same origin).
  • Install PWA from LAN URL: open the same http://<LAN-IP>:<port> on each device and use “Add to Home Screen / Install app”. Keep the same IP+port when starting the server.
  • Security: set a strong PM_WEB_SECRET_KEY for shared/LAN access, allow the port in firewall for trusted networks only, and prefer HTTPS reverse proxy/VPN outside trusted LAN. Some browsers limit full PWA install/offline features on non-localhost HTTP origins.
